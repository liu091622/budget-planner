# 预算规划助手 (Budget Planner)

> 一款为年轻人打造的轻量级预算规划工具。建议不强制，输入要快，数据私有。

## 快速开始

无需安装依赖，任选一种方式：

1. 直接双击打开 `index.html`。
2. 或启动本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## MVP 功能

* **F1 收支录入**：记录金额、分类、备注和日期，支持编辑、删除与录入校验。
* **F2 分配方案生成**：按 50/30/20、60/25/15 或 40/30/30 规则，根据本月收入生成分类额度；可逐项调整，总额始终等于收入。
* **F3 乱花钱提醒**：分类额度达到 80% / 100%、最近 7 天同类高频消费、单笔金额高于近 30 天同类均值 2 倍时给出中性提醒；可忽略 24 小时。
* **F4 省钱思路**：基于当月消费结构生成 3–5 条建议，标注数据依据与估算口径；无数据时降级为通用建议。

## 数据存储

所有数据仅保存在浏览器 `localStorage` 中，键名为 `budget-planner:v1`，不会上传服务器。清除浏览器站点数据会同时清空记录。页面底部提供“清空所有数据”入口。

## 文件结构

```text
index.html   页面结构
styles.css   基础样式与响应式布局
app.js       数据层与全部交互逻辑
docs/PRD.md  产品需求文档
```

## 版本规划

* **V1 (MVP)**：F1 收支录入、F2 分配方案、F3 乱花钱提醒、F4 省钱思路
* **V1.1**：F5 购物性价比参考、预警阈值用户自定义
* **V2**：F6 旅行与活动预算、自定义分类、多设备同步
